# השמירונית — לוח שמירות מחנה

אתר בעברית (RTL) לניהול וקריאה של גיליון השמירות: מי שומר עכשיו, איפה ומתי, חיפוש, המשמרות האישיות, החלפות ומעקב עומס. אתר סטטי (HTML/CSS/JS ללא תלויות) בסגנון [הניווטיה](https://github.com/captenfufu/nivutia), מיועד ל-GitHub Pages, עם מצב יום/לילה ורספונסיביות מלאה לנייד.

## מה יש באתר

1. **עכשיו** — מי על כל עמדה כרגע (פריקאסט / פטרול / ש״ג), כמה זמן נותר, המשמרת הבאה ומה קורה בשלוש השעות הקרובות. אפשר "לדפדף בזמן" (יום + שעה) כדי לראות כל רגע במחנה.
2. **המשמרות שלי** — בוחרים שם (נשמר במכשיר): ספירה לאחור למשמרת הבאה, עם מי שומרים, סה״כ שעות מול הממוצע, ייצוא ליומן (‎.ics עם תזכורת 5 דק׳ לפני), שיתוף בוואטסאפ וקישור אישי (`?name=…`).
3. **לוח שמירות יומי** — טבלה לפי שעות ועמדות לכל יום, צבע לכל צוות, סימון השורה הנוכחית, הדגשת חייל, והדפסה (A4 לרוחב). בחירת "לוח של צוות" מציגה רק את המשמרות של הצוות (נשמר במכשיר; קישור ישיר: `?team=3`).
4. **חיפוש וסינון** — חיפוש חופשי (שם, עמדה, צוות, פעילות — למשל ״פטרול צוות 3״) + סינון לפי יום, צוות, עמדה, סוג וטווח שעות, מיון וייצוא ל-CSV.
5. **החלפות** — החלפה הדדית בין שני חיילים או "מישהו מחליף אותי", עם בדיקה אוטומטית: חפיפה, משמרות צמודות / פחות משעה מנוחה, לילה למי שלא ישן בשטח, וזוג מצוותים שונים. הצעת מועמדים פנויים (מעט שעות, אותו צוות, בלי התנגשות). כל משמרת בלוח נפתחת בחלון עם אפשרות החלפה.
6. **חיילים ועומס** — סיכום לכל צוות ולכל חייל (משמרות, שעות, לילה, יום, ש״ג, משמרת הבאה) וסימון חריגים מהממוצע.
7. **נהלים** — כללי השמירה מתוך לשונית "הסבר וסיכום".

**התראה 5 דקות לפני משמרת:** ב"המשמרות שלי" בוחרים 🔔 "המשמרות שלי" או "כל המשמרות" (למפקד/ת). ההתראה כוללת את העמדה והשעה, מי נכנס ואת מי מחליפים (מי שמסיים באותה עמדה). ההתראות מגיעות כשהאתר פתוח בדפדפן (גם בלשונית ברקע). באייפון צריך קודם להוסיף את האתר למסך הבית (שיתוף ← "הוספה למסך הבית") ולהפעיל משם. אתר סטטי לא יכול לשלוח התראה כשהדפדפן סגור לגמרי, ולכן ליתר ביטחון "הוספה ליומן" מוסיפה לכל משמרת תזכורת 5 דקות לפני עם אותם פרטים, והיא עובדת גם כשהאתר סגור.

**חיפוש לפי שם פרטי:** בכל שדה שם אפשר להקליד רק שם פרטי (או תחילת שם / שם משפחה). אם יש התאמה אחת — היא משלימה לשם המלא; אם יש כמה (למשל שני ״איתי״) — מוצגים כפתורים לבחירה.

## מקור הנתונים

- הגדרות ב-`js/config.js` (מזהה הגיליון ומזהי הלשוניות "רשימת שמירות" ו"חיילים").
- האתר קורא את הגיליון **בזמן אמת** (הגיליון משותף "כל מי שיש לו קישור"), ומתרענן כל 2 דקות.
- אם אין חיבור — מוצגת הגרסה האחרונה שנטענה במכשיר, ואם אין כזו — תמונת המצב המובנית ב-`js/data.js`.
- לשונית "רשימת שמירות" היא מקור האמת: שינוי שם בעמודת "שם השומר" מופיע באתר.

## החלפות — שני מצבים

**מצב מקומי (ברירת מחדל):** ההחלפה נשמרת רק במכשיר שביצע אותה ומסומנת "מקומי". ליד כל שינוי יש כפתור **"עדכון בגיליון"** שפותח בדיוק את התא הנכון, ו"שיתוף בוואטסאפ" לשליחת סיכום.

**מצב מחובר (מומלץ) — Apps Script:** החלפות נכתבות ישירות לגיליון ומתועדות בלשונית "יומן החלפות".
1. בגיליון: **הרחבות ← Apps Script**, הדביקו את `apps-script/Code.gs`.
2. (רשות) **הגדרות הפרויקט ← מאפייני סקריפט**: `SWAP_PIN` = קוד שהאתר יבקש לפני החלפה.
3. **פריסה ← פריסה חדשה ← אפליקציית אינטרנט**, הפעלה בתור: *אני*, גישה: *כל אחד*.
4. העתיקו את כתובת `/exec` ל-`APPS_SCRIPT_URL` ב-`js/config.js` (לכולם) או להגדרות ⚙️ באתר (רק למכשיר הזה).

הסקריפט בודק שהשם בגיליון לא השתנה מאז הטעינה (מונע דריסה של החלפה של מישהו אחר), ומבצע את כל השינויים יחד או כלום.

## מבנה

```
index.html            דף יחיד עם כל הסעיפים
css/style.css         עיצוב (מוטיב צבאי-טופוגרפי) + Dark mode + רספונסיבי + הדפסה
js/config.js          הגדרות הגיליון והעמדות
js/data.js            תמונת מצב של הגיליון (גיבוי)
js/app.js             כל הלוגיקה
sw.js                 Service worker להצגת התראות
manifest.json, icon*  התקנה כאפליקציה (מסך הבית)
apps-script/Code.gs   סקריפט לסנכרון החלפות לגיליון (אופציונלי)
```

## הרצה מקומית

```bash
python3 -m http.server 8731
# פתחו http://localhost:8731
```
